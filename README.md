# 📊 Transition Command Center

An enterprise-grade BPO Transition Monitoring Dashboard built with **Streamlit**, **Pandas**, and **Matplotlib**. This tool is designed to track complex migrations (FnA, SCM, HRO) from international clients to delivery centers.

## 🚀 Live Demo
https://transition-command-center-hwyfkbtfvwcitg94dufcwg.streamlit.app/]

## 🛠 Features
*   **Two-Way Filtration:** Drill down into project health by specific Metro Location and Task Status.
*   **Automated Risk Detection:** Uses custom logic to flag "At Risk" tasks based on progress-to-timeline ratios.
*   **Financial Control:** Real-time monitoring of Budget vs. Actual Cost to identify financial slippage.
*   **Executive Reporting:** Generates professional PDF reports with high-res roadmaps and critical action tables.

## 📂 Project Structure
*   `app.py`: Main Streamlit application logic.
*   `Project Management.csv`: Central repository for transition data.
*   `requirements.txt`: Python dependencies.
